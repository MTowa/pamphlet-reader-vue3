# 公開前の確認

この一覧は、リリース候補を確認するためのものです。チェックを終えてもnpm公開やGitタグ作成は自動では実行しません。

## 自動テストで確認する範囲

`pnpm check` は実際の配布ファイルを独立Vue・Nuxtアプリにインストールし、PCのChromium・Firefox・WebKitと、Pixel 7／iPhone 13相当の表示を確認します。
PDF／SVG、ページ移動、読み込みエラーと再試行、言語切り替え、画面幅の変更、Workerの解放、Nuxt SSR、紹介サイトのコピー操作が対象です。

PlaywrightのWebKitはSafariそのものではありません。iPhone相当のテストではタッチイベントを再現していますが、実機のスクロールやジェスチャーの競合までは証明できません。[Playwrightのブラウザー説明](https://playwright.dev/docs/browsers#webkit)と[タッチイベントの説明](https://playwright.dev/docs/touch-events)を参照してください。

## 実機で確認する項目

**実機確認は未完了です。** [紹介サイト](https://mtowa.github.io/pamphlet-reader-vue3/)で、iPhoneのSafariとAndroidのChromeを対象に、以下を確認してください。修正が入った場合は、その修正を含むサイトで確認します。

- [ ] PDFとSVGの両方で、表紙から最後のページまで前後にめくれる。
- [ ] 左右のスワイプとサイトの縦スクロールを使い分けられ、操作が止まらない。
- [ ] 縦向き・横向きを切り替えても、ページがはみ出さず、読んでいたページを維持する。
- [ ] 手元のPDFを選んで開ける。普段使用する資料の文字・画像・ページ順が正しい。
- [ ] 日本語／Englishを切り替えても資料とページ位置を維持する。
- [ ] コードをコピーして別の入力欄に貼り付けられる。拒否された場合は手動コピーの案内が出る。
- [ ] 全画面ボタンがある環境では表示・終了できる。非対応環境ではボタンが出ない。

## 配布と公開

- [ ] バージョン、CHANGELOG、READMEの配布ファイル名が一致している。
- [ ] リリース候補に対する `pnpm check` と `pnpm build:site`、GitHubの自動チェックが成功している。
- [ ] `.artifacts/package-verification.json` の `verified` が `true` で、公開対象の配布ファイルを指している。
- [ ] READMEのVue／Nuxt導入例を確認し、第三者の全文ライセンス18点が配布物に含まれている。
- [ ] 公開直前にnpmの名前の使用状況と公開アカウントを確認する。
- [ ] ユーザーからnpm公開・タグ作成それぞれの明示的な承認を得る。

公開が成功した後に、READMEと紹介サイトの「npm公開前」の案内を更新します。公開手順は[releasing.md](releasing.md)、対応範囲と制限は[verification.md](verification.md)を参照してください。
