# Changelog

## 0.1.0 — 2026-11-15

- Chromium, Firefox and WebKit coverage, including mobile emulation, and a physical-device release checklist.
- Working documentation links in the packaged README and a version-aware introduction-site install command.
- Japanese/English viewer controls and introduction site with PDF/SVG examples.

- Adopt the package name `vue-leafbook`, update imports and installation examples, and migrate SVG indexes generated by the earlier development package.
- SVG directory sources with automatic numeric page ordering, static manifests, Vite/Nuxt development watchers, and lazy image rendering without PDF.js or a Worker.
- Shared page rendering contract, SVG/PDF source switching, and SVG examples with matching original artwork.
- Vue3 FlipbookViewer with URL/File sources, PDF.js rendering and StPageFlip adapter.
- Automatic inline workers and lazy packaged CMap/font/WASM support assets.
- Responsive spread/single-page modes, optional cover and toolbar, fullscreen and scoped keyboard navigation.
- One-based typed props, events and navigation methods.
- Bounded nearby-page canvas rendering, render cancellation, source replacement and complete component cleanup.
- Reproducible StPageFlip2.0.7 lifecycle fix.
- Vue+Vite and Nuxt4 playgrounds with original redistributable PDFs.
- Unit tests, production tarball consumer browser tests and GitHub Actions CI.
- Complete source/package license inventory, QuickJS notices, StPageFlip patch attribution, and checks for missing or altered third-party texts in installed tarballs.

Published as [vue-leafbook@0.1.0](https://www.npmjs.com/package/vue-leafbook/v/0.1.0) from [v0.1.0](https://github.com/MTowa/pamphlet-reader-vue3/tree/v0.1.0).
