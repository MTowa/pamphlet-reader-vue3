# Changelog

## 0.1.0 — Unreleased

- Vue3 FlipbookViewer with URL/File sources, PDF.js rendering and StPageFlip adapter.
- Automatic inline workers and lazy packaged CMap/font/WASM support assets.
- Responsive spread/single-page modes, optional cover and toolbar, fullscreen and scoped keyboard navigation.
- One-based typed props, events and navigation methods.
- Bounded nearby-page canvas rendering, render cancellation, source replacement and complete component cleanup.
- Reproducible StPageFlip2.0.7 lifecycle fix.
- Vue+Vite and Nuxt4 playgrounds with original redistributable PDFs.
- Unit tests, production tarball consumer browser tests and GitHub Actions CI.

This version has not been released to npm and has no release tag.
